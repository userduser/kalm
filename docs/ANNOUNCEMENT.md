# Preview announcement

Kalm is an open-source ad blocker with built-in YouTube comment screening. It has
a simple filtering slider, an optional all-links filter, and a shared list for
bot links and keywords. Development builds for Chrome, Firefox and Safari are
available. I'm looking for testers before the first fully verified release.

Source and preview downloads: https://github.com/userduser/kalm

Use this wording while native Firefox/Safari checks and store signing are
pending. After the release gate passes, update the announcement with actual
tested browser versions and installation links. Avoid guarantees that every ad
or bot comment will be blocked, or claims of classic dynamic-filtering parity.
